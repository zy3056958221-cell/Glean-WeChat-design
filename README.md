# 把 Markdown 一键排成可直接粘贴进公众号的精致 HTML

给 AI Agent（Claude Code / Codex / Cursor 等）用的公众号排版 Skill。你负责写，它负责排——Markdown、Word、PDF、纯文本进去，样式全内联、粘到公众号不掉格式的 HTML 出来。

`样式全内联不掉格式` · `6 套精选主题 + 主题生成器` · `双脚本质量校验` · `开源免费 AGPL-3.0`

---

## 它在做什么

| 项目 | 说明 |
|---|---|
| **服务内容** | 把长文转成公众号编辑器可直接使用的 HTML 正文片段，自动完成章节编号、代码块、图片与 GIF、行内链接、作者签名区等排版工作。 |
| **支持的输入** | Markdown（`.md` / 直接粘贴）、Word（`.docx`）、PDF、纯文本；非 Markdown 会自动归一化成结构化草稿。 |
| **使用场景** | 观点与深度分析、教程与操作指南、测评与工具盘点、数据复盘与报告、访谈特稿、生活随笔、案例复盘、内刊手记。 |
| **使用方式** | 装进任意能读取 Skill 目录的 Agent，说一句「用摸鱼绿把这篇文章排成公众号 HTML」即可；也可直接说「一键排版」，自动推断结构并选主题。 |
| **交付方式** | 干净正文 HTML 文件 + 带「复制到公众号」按钮的预览页，浏览器点一下即把富文本复制到剪贴板，再去编辑器粘贴，免手动全选。 |
| **适用范围** | 微信公众号为主，另附企业微信兼容模式与整篇导出长图；不做普通网页、落地页、PPT、海报。 |
| **内容边界** | 本 Skill 只负责排版，不代写文章——先有内容，再用它排。 |
| **授权说明** | AGPL-3.0，免费开源；保留署名，衍生与二次分发需以同协议开源。 |

## 为什么选择它

**更稳定的排版交付体验**

排版逻辑沉淀在主题组件库和校验脚本里，不靠模型临场发挥。同样一篇文章，换模型、换时间，排出来的气质是一致的。

| 服务能力 | gzh-design-skill | 手动在编辑器里排 |
|---|---|---|
| 排版速度 | 一篇长文一次成型 | 逐段调字号、间距、颜色 |
| 主题一致性 | 6 套厚组件库 + 文章类型配方表 | 每次凭手感，篇与篇不统一 |
| 粘贴掉格式 | 样式全内联 + 文字节点 `<span leaf="">` 包裹，专门规避平台清洗 | 常见样式塌陷、字体丢失 |
| 平台禁用写法 | 校验脚本确定性拦截 | 靠经验，容易踩雷 |
| 代码块与图片 | 等宽代码块、GIF 角标、图片说明 | 手写 HTML，缩进和行距难控 |
| 换模型 | 逻辑在组件库，谁跑都一样 | 不适用 |

## 如何开始

四步完成排版，从安装到粘贴。

**01 安装**

一行装好：

```bash
npx skills add https://github.com/isjiamu/gzh-design-skill
```

也可以让 AI 自己装，或手动 clone 到 skills 目录。

**02 选主题**

按题材自动推荐最契合的主题并请你一步确认，也可自己指定。现成主题不够用，还能按一句话描述或一张参考图现造一套。

**03 装配与校验**

读取所选主题的组件库装配 HTML，跑 `validate_gzh_html.py` 把关平台红线和半角标点，ERROR 清零才交付。

**04 复制粘贴**

打开预览页点右上角「复制到公众号」，到编辑器直接粘贴；需要发企业微信或转长图，用同一页面的蓝色、紫色按钮。

## 两个容易被低估的能力

**企业微信兼容模式**：企业微信不抓外链图，粘贴后图片会消失。本 Skill 支持把本地图内联成 base64；外链图可在预览页点「复制到企业微信」按钮，在浏览器里完成内联。若目标编辑器连 base64 都清洗，还能一键把整篇导出成一张长图 PNG，走图片上传通道，彻底不丢图。

**双关卡质量校验**：`component_lint.py` 守组件库源头，`validate_gzh_html.py` 守最终产物，构成可复现的「改 → 验 → 修」闭环。平台禁用的是非靠模型自觉，而是脚本确定性检查。

## 适合谁用

**适合**：常年写公众号的创作者与运营、需要批量产出内容的小团队、想把手上的 Word / PDF 旧稿重新排版上号的人，以及正在用 Claude Code / Codex / Cursor 写稿、想把「排版」这一步也交给 AI 的人。

**不适合**：想生成普通网页或落地页、想要 PPT、想要海报或社交卡片、以及想让 AI 代写整篇文章的人。本 Skill 只解决「排」这一步。

---

## 使用前须知

- 本 Skill 只排版，不写作；请先准备 Markdown / Word / PDF / 纯文本内容。
- 交付前请跑一遍校验脚本，ERROR 清零、半角标点 WARNING 归零后再粘贴。
- 签名区默认使用占位署名，交付时会提示你替换成自己的署名。
- 采用 AGPL-3.0，保留版权与联名署名；修改版、Fork、二次分发需以同协议开源。
